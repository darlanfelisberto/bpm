b:autocomplete

b:autocomplete

Text input with server-driven suggestions dropdown, equivalent to PrimeFaces' p:autoComplete. Integrates natively with standard JSF form submission (UIInput) and supports both plain string lists and complex objects with a Converter.

Data loading

The completeMethod attribute points to a bean method that takes the typed query string and returns a List<T> of matching items. Queries are automatically debounced (default 300ms) and only sent when the input length reaches minQueryLength (default 1).

Attributes — b:autocomplete

AttributeRequiredDescription
valueYesValue binding for the selected object or text (standard UIInput value).
completeMethodYesMethod expression that returns suggestion items (e.g. \#{bean.complete(query)}).
varNoName of the EL variable exposed when iterating over POJO suggestions.
itemLabelNoLabel shown in suggestions and in the input when an item is selected (e.g. \#{p.name}).
itemValueNoValue of the item passed to the converter/model (e.g. \#{p}).
converterNoConverter for transforming between object instances and string identifiers.
minQueryLengthNoMinimum number of characters required to trigger query (default 1).
queryDelayNoDebounce delay in milliseconds before sending query (default 300).
dropdownNoIf true, displays a dropdown button to trigger suggestions without typing (default false).
dropdownModeNoWhen dropdown button is clicked: blank sends empty query (default), current sends current input text.
forceSelectionNoIf true, reverts to previously selected value if free text does not match any suggestion (default false).
placeholderNoPlaceholder text for the input field.
emptyMessageNoMessage shown when no results are found. Defaults to translated text (autocomplete.noResults).
maxResultsNoMaximum number of suggestions displayed.
disabledNoDisables input and dropdown button (default false).
readonlyNoMakes the input read-only (default false).
style / styleClassNoCSS style and style class for the root container.
inputStyle / inputStyleClassNoCSS style and style class for the text input.

Client behaviors (nested f:ajax)

EventFires when
itemSelecta suggestion item is selected (default event).
changethe input value changes.
clearthe clear button (×) is clicked.
querya search query is dispatched to the backend.

Example

<!-- Plain string autocomplete with dropdown button -->
<b:autocomplete value="\#{bean.selectedCity}"
                completeMethod="\#{bean.completeCity}"
                dropdown="true"
                placeholder="Type or click dropdown...">
    <f:ajax event="itemSelect" listener="\#{bean.onCitySelect}" render=":result"/>
</b:autocomplete>

<!-- POJO autocomplete with Converter and forceSelection -->
<b:autocomplete value="\#{bean.selectedPerson}"
                completeMethod="\#{bean.completePerson}"
                var="p"
                itemLabel="\#{p.name}"
                itemValue="\#{p}"
                converter="\#{personConverter}"
                forceSelection="true"
                dropdown="true"
                placeholder="Search person by name, email or role...">
    <f:ajax event="itemSelect" listener="\#{bean.onPersonSelect}" render=":result"/>
</b:autocomplete>
