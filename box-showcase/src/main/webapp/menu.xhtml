b:menu

b:menu

Vertical navigation menu container for statically declared items in XML. Supports navigation links (outcome, url), server/ajax actions, badges, icons, grouping via b:submenu (with collapsible behavior) and section dividers via b:separator.

Attributes — b:menu

AttributeRequiredDescription
headerNoTitle shown at the top of the menu container.
styleNoInline CSS style.
styleClassNoCustom CSS class.

Attributes — b:menuitem

AttributeRequiredDescription
value / labelNoText label shown for this menu item.
outcomeNoTarget view ID for bookmarkable JSF GET navigation (e.g. /index).
url / hrefNoTarget URL for direct/external link (e.g. https://example.com).
iconNoCSS icon class (e.g. bi bi-house).
badgeNoBadge text or counter displayed at the right edge.
badgeClassNoCSS class applied to the badge.
targetNoTarget browsing context for links (e.g. _blank).
activeNoExplicitly mark item as active. If omitted, matches current view ID automatically.
disabledNoDisables click and applies disabled style. Defaults to false.
actionNoMethodExpression invoked when clicking the item (submit/ajax).
actionListenerNoMethodExpression for action listener.
onclickNoClient-side click handler script.

Attributes — b:submenu

AttributeRequiredDescription
labelNoHeader title for the grouped section.
iconNoCSS icon class for the section header.
expandedNoWhether the submenu starts open. Defaults to true.
collapsibleNoWhether clicking the section header toggles open/closed. Defaults to true.

Attributes — b:separator

AttributeRequiredDescription
labelNoOptional section label displayed on the divider line.

Example 1 — Navigation menu with groups, icons and badges

<b:menu header="Navigation">
    <b:menuitem value="Home" outcome="/index" icon="bi bi-house"/>
    <b:submenu label="Components" icon="bi bi-collection">
        <b:menuitem value="Panel" outcome="/panel" icon="bi bi-card-text"/>
        <b:menuitem value="Popup" outcome="/popup" icon="bi bi-window"/>
        <b:menuitem value="Datatable" outcome="/datatable" icon="bi bi-table" badge="New"/>
        <b:menuitem value="Disabled Item" outcome="/index" icon="bi bi-slash-circle" disabled="true"/>
    </b:submenu>
    <b:separator label="External Links"/>
    <b:menuitem value="Documentation" url="https://jakarta.ee" target="_blank" icon="bi bi-box-arrow-up-right"/>
</b:menu>

Example 2 — Actions with AJAX

Menu items without outcome or url behave as command buttons triggering server actions and AJAX updates.

<h:form id="menuForm">
    <b:growl/>
    <b:menu header="Quick Actions" style="max-width: 260px;">
        <b:menuitem value="Sync Database" icon="bi bi-arrow-repeat" action="\#{menuDemoBean.executeAction('Sync Database')}">
            <f:ajax execute="@this" render="@form"/>
        </b:menuitem>
        <b:menuitem value="Generate Report" icon="bi bi-file-earmark-pdf" action="\#{menuDemoBean.executeAction('Generate Report')}">
            <f:ajax execute="@this" render="@form"/>
        </b:menuitem>
    </b:menu>
    <h:outputText id="actionResult" value="\#{menuDemoBean.lastAction}"/>
</h:form>
