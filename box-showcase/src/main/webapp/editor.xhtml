b:editor

Editor de texto rico usando Quill (auto-hospedado, sem CDN) como motor de edição. Componente nativo UIInput (não composite): integra com value/validação como qualquer input do Faces, só a renderização é manual.

O valor persistido é HTML (inclusive imagens coladas, como data URI embutida), sanitizado no servidor com Jsoup antes de gravar — único ponto de defesa contra XSS armazenado, já que o cliente é só Quill/JS e um POST forjado pode mandar qualquer coisa direto pro servidor. Quem exibir o valor precisa usar escape="false" (ex.: h:outputText), já que ele contém marcação.

Atributos

AtributoObrigatórioDescrição
valueSimExpressão EL apontando pra uma propriedade String — recebe o HTML sanitizado.

Exemplo

<b:editor id="objetivo" value="\#{bean.objetivo}"/>
...
<h:outputText value="\#{bean.objetivo}" escape="false"/>

Conteúdo salvo (h:outputText escape="false")
