b:editor

Rich text editor using Quill (self-hosted, no CDN) as the editing engine. Native UIInput component (not a composite): it integrates with value/validation like any Faces input, only the rendering is manual.

The persisted value is HTML (including pasted images, as an embedded data URI), sanitized server-side with Jsoup before saving — the only line of defense against stored XSS, since the client is just Quill/JS and a forged POST could send anything straight to the server. Whoever displays the value needs to use escape="false" (e.g. h:outputText), since it contains markup.

Attributes

AttributeRequiredDescription
valueYesEL expression pointing to a String property — receives the sanitized HTML.

Example

<b:editor id="objetivo" value="\#{bean.objetivo}"/>
...
<h:outputText value="\#{bean.objetivo}" escape="false"/>

Saved content (h:outputText escape="false")
