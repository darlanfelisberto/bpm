box-showcase

Showcase of the native Jakarta Faces components from the box lib (module br.edu.iffar:box, reusable across IFFar projects). Each page below shows the component working for real and the XHTML snippet to reproduce it.

Box with an optional title (equivalent to a card).

Inline confirmation before an action (e.g. delete), in both forms: nested inside an h:commandLink/h:commandButton or via the plain data-box-confirm attribute, with no Faces component.

Rich text editor (Quill): bold, italic, underline, strikethrough, font, size, color, alignment, lists, quote, code, link, pasting images.

Modal popup, equivalent to p:dialog, based on the native <dialog> element — focus, Esc and backdrop come for free from the browser.

Messages (FacesMessage) shown as floating toasts, equivalent to p:growl.

Event calendar (FullCalendar): month/week/day views, create an event by selecting a range, move and resize events by dragging, click an event — all reported via nested f:ajax.

Same idea as b:schedule, but with no external lib — only month view, hand-written in vanilla JS, to compare against the FullCalendar-based version.

Table with pagination, sorting and per-column filtering, lazy — every interaction calls the backend again, without keeping rows in the view state.
