box-showcase

Vitrine dos componentes Jakarta Faces nativos da lib box (módulo br.edu.iffar:box, reutilizável entre projetos do IFFar). Cada página abaixo mostra o componente funcionando de verdade e o trecho de código XHTML pra reproduzi-lo.

Quadro com título opcional (equivalente a um card).

Confirmação inline antes de uma ação (ex.: excluir), nas duas formas: aninhado num h:commandLink/h:commandButton ou via atributo data-box-confirm, sem nenhum componente Faces.

Editor de texto rico (Quill): negrito, itálico, sublinhado, tachado, fonte, tamanho, cor, alinhamento, listas, citação, código, link, colar imagens.

Mensagens (FacesMessage) exibidas como toasts flutuantes, equivalente ao p:growl.

Agenda de eventos (FullCalendar): visões mês/semana/dia, criar evento selecionando um intervalo, mover e redimensionar eventos arrastando, clicar num evento — tudo reportado via f:ajax aninhado.

Mesma ideia do b:schedule, mas sem nenhuma lib externa — só visão de mês, escrita à mão em JS vanilla, pra comparar com a versão que usa FullCalendar.
