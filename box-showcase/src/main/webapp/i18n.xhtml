Multilingual text

User-visible text generated by box components (box-confirm, b:popup, b:growl, b:datatable) is resolved entirely in JS, at render time, from document.documentElement.lang — never by the Java side. box-core.js ships only the English dictionary (Box.messages.en); the box lib itself never assumes any other language.

To add a language, an app just registers its own translations for the same keys, in a small JS file included after box-core.js:

// resources/js/i18n-pt.js, included via <h:outputScript>
document.addEventListener('DOMContentLoaded', function () {
    window.Box.messages.pt = {
        'confirm.yes': 'Confirmar',
        'confirm.no': 'Cancelar',
        'confirm.defaultMessage': 'Tem certeza?',
        // ... rest of the keys, see Box.messages.en in box-core.js
    };
});

This page includes resources/js/i18n-pt.js (the snippet above) — switch the language below and click the button to see box-confirm resolve its text from the matching dictionary, live, with no round trip to the server.
