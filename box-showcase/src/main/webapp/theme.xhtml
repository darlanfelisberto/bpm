Themes - box-showcase

Theming and CSS Architecture

The box component library is built on CSS custom properties (variables) managed via Dart Sass. Themes can be switched dynamically per-page or per-container, and respect system dark mode preferences automatically.

Live Theme Preview

Use the buttons below to switch the theme dynamically across the showcase, or use the selector in the top navigation bar. Preferences are saved in localStorage.

Interactive Component Samples in Current Theme

All colors, shadows, borders and focus rings adapt instantly when switching themes.

Scoped Themes (Container-level)

A theme class (such as box-theme-dark or box-theme-default) can be applied to any container element, allowing dark cards inside light pages or vice-versa.

Forced Light Container (.box-theme-default)

Always rendered with the light theme palette regardless of page theme.

Forced Dark Container (.box-theme-dark)

Always rendered with the dark theme palette regardless of page theme.

Theme CSS Variables

Components consume standard CSS custom properties defined in box.css:

CSS Variable Default (Light) Dark Description
--color-primary #2f6f4f (IFFar Green) #4ade80 Main brand color for active items, borders and accents
--color-primary-dark #24563e #22c55e Hover and pressed states for primary elements
--color-primary-contrast #ffffff #052e16 Text color on top of primary background
--color-surface #ffffff #1e293b Cards, dropdown panels, popups and menus background
--color-bg #f4f6f8 #0f172a Page background and secondary surfaces
--color-text #1f2933 #e2e8f0 Primary body text color
--color-text-muted #616e7c #94a3b8 Secondary labels, headers and placeholders
--color-border #dfe4ea #334155 Component borders and dividers
--color-danger #b3261e #f87171 Error messages, destructive actions, danger badges
--color-warn #b58105 #fbbf24 Warning toasts and notices
--radius 8px 8px Default border radius for containers
--shadow 0 1px 2px rgba(16,24,32,0.06) 0 1px 4px rgba(0,0,0,0.4) Component shadow elevation

Creating a Custom Theme

To create a custom theme (e.g. .box-theme-ocean), define the custom properties in a SASS partial: 

/* src/main/sass/themes/_ocean-theme.scss */
.box-theme-ocean {
  --color-primary:          #0284c7;
  --color-primary-dark:     #0369a1;
  --color-primary-contrast: #ffffff;
  --color-danger:           #e11d48;
  --color-warn:             #f59e0b;
  --color-success:          #10b981;
  --color-text:             #0f172a;
  --color-text-muted:       #64748b;
  --color-surface:          #ffffff;
  --color-bg:               #f0f9ff;
  --color-border:           #bae6fd;
  --shadow:                 0 1px 3px rgba(2, 132, 199, 0.1);
  --radius:                 8px;
}

Import it in src/main/sass/box.scss and recompile via mvn install -pl box.
