b:question

b:question

A native assessment and survey question component. Renders questions in either Descriptive format (multi-line <textarea>) or Choice format (single-choice <input type="radio"> list). Designed for seamless integration with database entities via generic Java interfaces (QuestionModel, QuestionOption, QuestionType), as well as direct declarative attribute usage.

Attributes — b:question

AttributeRequiredDescription
valueNoThe current answer value bound to a bean property (String for descriptive, Option ID/value for choice).
modelNoInstance of QuestionModel supplying prompt, type, options, required flag, etc.
promptNoQuestion statement or prompt text. Overrides model.prompt if specified.
typeNoFormat of the question: DESCRIPTIVE or CHOICE.
optionsNoCollection of options (items implementing QuestionOption, SelectItem, or plain Objects).
numberNoDisplay index or label (e.g. 1, "Questão 1").
descriptionNoSupplementary instructions or help text displayed below the prompt.
placeholderNoPlaceholder text for the descriptive <textarea>.
rowsNoVisible line rows for descriptive textarea (default: 3).
colsNoVisible columns for descriptive textarea.
requiredNoWhether an answer is required. Displays an asterisk indicator.
disabledNoDisables user input and renders a muted style.
readonlyNoPrevents changing value while keeping normal appearance.
styleNoInline CSS style for the outer container.
styleClassNoCustom CSS class for the outer container.

Client Behaviors

EventDescription
change / valueChangeFired when the user selects a radio alternative or finishes editing the descriptive textarea.
clickFired when a choice option is clicked.

Example 1 — Model-Driven Assessment (Database Entity Simulation)

Iterating through a list of questions retrieved from the database with AJAX auto-saving and full form submission:

<ui:repeat value="#{questionDemoBean.assessmentQuestions}" var="q" varStatus="st">
    <b:question model="#{q}"
                number="#{st.index + 1}"
                value="#{questionDemoBean.answers[q.id]}">
        <f:ajax event="change"
                listener="#{questionDemoBean.onAjaxAnswerChange(q.id)}"
                render=":demoForm:ajaxLog :demoForm:growlMsg"/>
    </b:question>
</ui:repeat>

Example 2 — Declarative Questions (Static XML Usage)

Using b:question directly without external models:

<!-- Choice Question -->
<b:question prompt="Select the issue priority level:"
            type="CHOICE"
            options="#{questionDemoBean.priorityOptions}"
            value="#{questionDemoBean.selectedPriority}"
            required="true"/>

<!-- Descriptive Question -->
<b:question prompt="Describe your feedback in detail:"
            type="DESCRIPTIVE"
            placeholder="Type your feedback here..."
            rows="4"
            value="#{questionDemoBean.feedbackText}"/>

Database Entity Integration Guide

To use JPA entities directly with b:question, simply implement the QuestionModel and QuestionOption interfaces:

@Entity
@Table(name = "questao", schema = "avaliacao")
public class Questao implements QuestionModel, Serializable {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, columnDefinition = "TEXT")
    private String enunciado;

    @Enumerated(EnumType.STRING)
    private TipoQuestao tipo;

    @OneToMany(mappedBy = "questao")
    private List<OpcaoQuestao> opcoes;

    // Bridge methods satisfying QuestionModel:
    @Override public Object getId() { return id; }
    @Override public String getPrompt() { return enunciado; }
    @Override public QuestionType getType() {
        return tipo == TipoQuestao.TEXTO_LIVRE ? QuestionType.DESCRIPTIVE : QuestionType.CHOICE;
    }
    @Override public List<? extends QuestionOption> getOptions() { return opcoes; }
}
