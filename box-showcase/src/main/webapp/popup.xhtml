b:popup

b:popup

Popup modal, equivalente ao p:dialog, baseado no elemento nativo <dialog> — foco, Esc e empilhamento (top layer) são o próprio browser cuidando disso, sem reimplementar nada em JS. Abrir/fechar é sempre client-side (Box.popup.abrir('id')/Box.popup.fechar('id')) — sem atributo visible/estado nenhum guardado no bean. Quando o bean precisa fechar o popup como reação a uma ação (ex.: só fechar depois de salvar sem erro), ele manda o cliente executar Box.popup.fechar(...) via PartialViewContext.getEvalScripts() — o canal nativo do Jakarta Faces pra rodar JS junto da resposta ajax, equivalente ao RequestContext.execute() do PrimeFaces. Ver exemplo mais abaixo.

Atributos

AtributoObrigatórioDescrição
headerNãoTítulo exibido no cabeçalho. Alternativa mais simples à facet header (útil quando o título é só texto).
closableNãoSe false, remove o botão de fechar e desliga fechar por clique fora/Esc. Padrão true.

Facets

FacetDescrição
headerCabeçalho com marcação, quando um texto simples não é suficiente.
footerRodapé — normalmente os botões de ação (ex.: Salvar/Cancelar).

Exemplo

<b:popup id="dlg" header="Editar item">
    Conteúdo qualquer aqui dentro.
    <f:facet name="footer">
        <h:commandButton value="Fechar" onclick="Box.popup.fechar('dlg'); return false;"/>
    </f:facet>
</b:popup>

<h:commandButton value="Abrir popup" onclick="Box.popup.abrir('dlg'); return false;"/>

Conteúdo qualquer aqui dentro — formulário, texto, o que precisar.

Esc e clique fora não fecham este popup — só o botão do rodapé.

Exemplo — bean fechando o popup depois de salvar

"Abrir" continua 100% client-side. "Salvar" executa a ação no bean (que só atualiza ultimoSalvamento) e manda fechar o popup via script — por isso o render do botão não inclui o popup: quem fecha é o getScriptsToExecute(), não uma troca de <dialog>.

<b:popup id="dlgServidor" header="Novo instrumento">
    Conteúdo qualquer aqui dentro.
    <f:facet name="footer">
        <h:commandButton value="Salvar" action="\#{popupDemoBean.salvar}">
            <f:ajax execute="@form" render=":formPopupServidor:resultadoPopup"/>
        </h:commandButton>
    </f:facet>
</b:popup>

<h:commandButton value="Abrir" onclick="Box.popup.abrir('formPopupServidor:dlgServidor'); return false;"/>

// PopupDemoBean.salvar()
FacesContext.getCurrentInstance().getPartialViewContext()
        .getEvalScripts().add("Box.popup.fechar('formPopupServidor:dlgServidor')");

Conteúdo qualquer aqui dentro. Salvar fecha este popup por um script mandado pelo bean.
