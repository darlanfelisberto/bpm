b:popup

b:popup

Modal popup, equivalent to p:dialog, built on the native <dialog> element — focus, Esc and stacking (top layer) are handled by the browser itself, without reimplementing anything in JS. Opening/closing is always client-side (Box.popup.open('id')/Box.popup.close('id')) — no visible attribute, no state kept in the bean. When the bean needs to close the popup as a reaction to an action (e.g.: only close after saving without error), it tells the client to run Box.popup.close(...) via PartialViewContext.getEvalScripts() — the native Jakarta Faces channel for running JS alongside the ajax response, equivalent to PrimeFaces' RequestContext.execute(). See the example further below.

Attributes

AttributeRequiredDescription
headerNoTitle shown in the header. Simpler alternative to the header facet (useful when the title is just text).
closableNoIf false, removes the close button and disables closing by clicking outside/Esc. Defaults to true.

Facets

FacetDescription
headerHeader with markup, for when plain text isn't enough.
footerFooter — usually the action buttons (e.g.: Save/Cancel).

Example

<b:popup id="dlg" header="Edit item">
    Any content goes here.
    <f:facet name="footer">
        <h:commandButton value="Close" onclick="Box.popup.close('dlg'); return false;"/>
    </f:facet>
</b:popup>

<h:commandButton value="Open popup" onclick="Box.popup.open('dlg'); return false;"/>

Any content goes here — a form, text, whatever is needed.

Esc and clicking outside don't close this popup — only the footer button does.

Example — bean closing the popup after saving

"Open" is still 100% client-side. "Save" runs the action on the bean (which just updates lastSaved) and tells the popup to close via script — that's why the button's render doesn't include the popup: what closes it is getEvalScripts(), not a swap of the <dialog>.

<b:popup id="dlgServidor" header="New instrument">
    Any content goes here.
    <f:facet name="footer">
        <h:commandButton value="Save" action="\#{popupDemoBean.save}">
            <f:ajax execute="@form" render=":formPopupServidor:resultadoPopup"/>
        </h:commandButton>
    </f:facet>
</b:popup>

<h:commandButton value="Open" onclick="Box.popup.open('formPopupServidor:dlgServidor'); return false;"/>

// PopupDemoBean.save()
FacesContext.getCurrentInstance().getPartialViewContext()
        .getEvalScripts().add("Box.popup.close('formPopupServidor:dlgServidor')");

Any content goes here. Saving closes this popup via a script sent by the bean.
