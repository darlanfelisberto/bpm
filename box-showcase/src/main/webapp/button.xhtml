b:commandButton

b:commandButton

Enhanced button component (also available as b:button) that renders a native <button> element instead of <input type="submit">. Supports icons positioned to the left or right of the label, icon-only mode, visual variants, standard JSF actions and <f:ajax>, and allows nesting child elements like <box-confirm>.

Attributes

AttributeRequiredDescription
value / labelNoThe text label displayed on the button.
iconNoCSS icon class, e.g. bi bi-floppy, bi bi-trash.
iconPosNoPosition of the icon relative to the label: left (default) or right.
variantNoVisual style variant: primary (default), secondary, success, danger, warning, outlined, text.
sizeNoButton size: sm, normal (default), or lg.
typeNoHTML button type: submit (default), button, or reset.
disabledNoDisables button interaction. Defaults to false.
actionNoMethodExpression invoked when clicking the button.
actionListenerNoMethodExpression for the action listener.
immediateNoExecutes the action in the Apply Request Values phase. Defaults to false.
onclickNoClient-side JavaScript handler. If it returns false, submission/ajax is canceled.
titleNoAdvisory tooltip title. Also used as aria-label when no text label is present.
ariaLabelNoAccessible label for screen readers.
styleNoInline CSS styles.
styleClassNoExtra CSS class names.

Client Behaviors

EventDefaultDescription
actionYesFires when the button is activated. Works with <f:ajax> without an explicit event name.
clickNoFires on client-side click.
dblclickNoFires on client-side double click.
focusNoFires when button receives focus.
blurNoFires when button loses focus.

1. Icon Placement

Icons can be placed to the left or right of the label, or used alone without label text.

<!-- Left icon (default) -->
<b:commandButton value="Save" icon="bi bi-floppy" />

<!-- Right icon -->
<b:commandButton value="Next" icon="bi bi-arrow-right" iconPos="right" />

<!-- Icon only (automatically adapts styling and accessibility) -->
<b:commandButton icon="bi bi-pencil" title="Edit" />
<b:commandButton icon="bi bi-trash" title="Delete" variant="danger" />

2. Visual Variants

Built-in variants styled with Box CSS custom properties (light and dark theme compatible).

<b:commandButton value="Primary" icon="bi bi-check-lg" />
<b:commandButton value="Secondary" icon="bi bi-gear" variant="secondary" />
<b:commandButton value="Success" icon="bi bi-check-circle" variant="success" />
<b:commandButton value="Danger" icon="bi bi-trash" variant="danger" />
<b:commandButton value="Warning" icon="bi bi-exclamation-triangle" variant="warning" />
<b:commandButton value="Outlined" icon="bi bi-bookmark" variant="outlined" />
<b:commandButton value="Text" icon="bi bi-link-45deg" variant="text" />

3. Button Sizes

Buttons support small (sm), default, and large (lg) sizes.

<b:commandButton value="Small" icon="bi bi-star" size="sm" />
<b:commandButton value="Default" icon="bi bi-star" />
<b:commandButton value="Large" icon="bi bi-star" size="lg" />

4. AJAX Submissions with f:ajax

Seamlessly integrates with <f:ajax> to update portions of the page asynchronously.

<h:form id="ajaxForm">
    <b:commandButton value="Increment Counter"
                     icon="bi bi-plus-circle"
                     action="\#{buttonDemoBean.increment}">
        <f:ajax render="counterDisplay statusMessage" />
    </b:commandButton>

    <b:commandButton value="Reset"
                     icon="bi bi-arrow-counterclockwise"
                     variant="secondary"
                     action="\#{buttonDemoBean.reset}">
        <f:ajax render="counterDisplay statusMessage" />
    </b:commandButton>
</h:form>

5. Nested <box-confirm>

Because b:commandButton renders a native <button> container element, <box-confirm> can be nested directly inside it (unlike standard h:commandButton which renders a void <input>). 

<b:commandButton value="Delete Item"
                 icon="bi bi-trash"
                 variant="danger"
                 action="\#{buttonDemoBean.execute('Item Deleted')}">
    <box-confirm message="Are you sure you want to permanently delete this item?"
                 yes-label="Yes, delete"
                 yes-class="box-button-danger"/>
    <f:ajax render=":confirmResult" />
</b:commandButton>

6. Disabled State

Buttons with disabled="true" apply visual styling and prevent click events.
