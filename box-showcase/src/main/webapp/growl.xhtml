b:growl

b:growl

Messages (FacesMessage) shown as floating toasts in the corner of the screen, equivalent to PrimeFaces' p:growl. Passive like h:messages: it only reads and displays messages that have already been added (FacesContext.addMessage) — the bean always decides what and when. That's why it needs to be in the render of the action that added the message, otherwise it stays queued but never shows up.

Attributes

AttributeRequiredDescription
forNoClientId whose messages to display. If omitted, shows all of them (global and from any component).
lifeNoMilliseconds until the toast disappears on its own. Defaults to 3000.
stickyNoIf true, the toast only disappears when the user clicks to close it. Defaults to false.

Example

<b:growl/>

<h:commandButton value="Save" action="\#{bean.save}">
    <f:ajax render=":growl"/>
</h:commandButton>
