box-confirm

Inline confirmation (popup near the clicked element, without blocking the thread like the browser's native confirm()) before proceeding with an action. A real custom element (customElements.define), nested as a plain child inside any link or button — no Faces component/behavior and no p:namespace passthrough needed, since it's an ordinary HTML tag and Facelets resolves EL in its attributes like any other literal markup. It hides itself and carries its configuration for a single document-level click listener (confirm.js) that reads it when the trigger is clicked. Must be nested inside an actual container element (h:commandLink, which renders <a>) — not h:commandButton, which renders a void <input> that can't hold children.

Attributes

AttributeRequiredDescription
messageNoText shown in the popup. Accepts EL. Omitted, falls back to a translated default message (see ).
yes-label / no-labelNoOverride the confirm/cancel button text (defaults to the translated confirm.yes/confirm.no).
yes-class / no-classNoExtra CSS class added to the confirm/cancel button, alongside box-confirm-yes/box-confirm-no.
<h:commandLink action="\#{bean.delete(item)}" styleClass="link-danger">
    Delete
    <box-confirm message="Delete \#{item}?" yes-label="Sim" yes-class="box-confirm-yes--custom"/>
    <f:ajax render=":form"/>
</h:commandLink>
