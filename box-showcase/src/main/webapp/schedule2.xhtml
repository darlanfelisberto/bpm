b:schedule2

Same idea as (event calendar), but with no external lib at all — to compare the result. The month grid, month navigation, and drag-and-drop are hand-written in vanilla JS, using native HTML5 Drag and Drop (draggable/ dragstart/dragover/drop).

What's missing, compared to b:schedule

Featureb:schedule (FullCalendar)b:schedule2 (vanilla)
Month viewYesYes
Week/day view (hour grid)YesNo
Resize eventYesNo
Multi-day event (continuous bar)YesNo — repeats the event on each day it touches
JS payload size~80KB (gzip)0 — just this schedule2.js

Client behaviors (nested f:ajax)

EventFires when
selectclicking an empty day
movedragging an event to another day
clickclicking an existing event

Example

<b:schedule2 events="\#{bean.events}">
    <f:ajax event="select" listener="\#{bean.onSelect}" render=":resultado"/>
    <f:ajax event="move" listener="\#{bean.onMove}" render=":resultado"/>
    <f:ajax event="click" listener="\#{bean.onClick}" render=":resultado"/>
</b:schedule2>
