b:schedule

b:schedule

Event calendar (month/week/day), equivalent to PrimeFaces' p:schedule. Uses FullCalendar (self-hosted, no CDN) as the engine — the same lib that p:schedule itself uses underneath. A native component that implements ClientBehaviorHolder: it only reports what happened (dragging to select, moving, resizing, clicking an event), and whoever decides what to do with that is the nested f:ajax listener — the component doesn't decide anything on its own, same as b:confirm doesn't decide what "confirming" does.

Attributes

AttributeRequiredDescription
eventsYesEL expression pointing to a List<ScheduleEvent>.

Client behaviors (nested f:ajax)

EventFires whenData available in the listener
selectdragging to select an empty rangeschedule.getStart() / getEnd()
movedragging an existing eventgetEventId(), new getStart()/getEnd()
resizeresizing an existing eventgetEventId(), new getEnd()
clickclicking an existing eventgetEventId()

Example

<b:schedule events="\#{bean.events}">
    <f:ajax event="select" listener="\#{bean.onSelect}" render=":resultado"/>
    <f:ajax event="move" listener="\#{bean.onMove}" render=":resultado"/>
    <f:ajax event="resize" listener="\#{bean.onResize}" render=":resultado"/>
    <f:ajax event="click" listener="\#{bean.onClick}" render=":resultado"/>
</b:schedule>
