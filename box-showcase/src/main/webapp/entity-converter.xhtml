b:entityConverter

Universal Jakarta Faces converter (box.entityConverter) designed to eliminate the need for writing individual Converter classes for every database entity. It serializes any identifiable object into a compact classHashCode@entityId representation and reconstructs the entity on postback by delegating lookups to an application-provided EntityResolver.

Key Features

  • Database decoupled: The box module has no JPA or persistence dependencies; applications supply their own lookup via CDI.
  • Zero manual registration: Entity classes are automatically registered in memory during getAsString.
  • Multi-type ID support: Automatically parses identifiers typed as UUID, Long, Integer, or String.
  • Automatic key extraction: Inspects either getId() or getMMId() out of the box.

How It Works

When rendering an HTML element (e.g. <option> or data-id), the converter outputs [class.hashCode]@[entity.id]. On submission, it parses the hash code to retrieve the entity class, converts the string ID to the entity's primary key type, and calls the registered EntityResolver.find(entityClass, id).

Providing the EntityResolver (Application Side)

In your application (e.g. bpm-app), implement the EntityResolver CDI interface to delegate lookups to your EntityManager: 

@ApplicationScoped
public class JpaEntityResolver implements EntityResolver {

    @Inject
    private EntityManager em;

    @Override
    public <T> T find(Class<T> entityClass, Object id) {
        return em.find(entityClass, id);
    }
}

Usage in XHTML

<!-- Option 1: Nested tag -->
<h:selectOneMenu value="\#{bean.selectedEntity}">
    <b:entityConverter/>
    <f:selectItems value="\#{bean.entities}" var="e" itemLabel="\#{e.name}" itemValue="\#{e}"/>
</h:selectOneMenu>

<!-- Option 2: converter attribute by ID -->
<h:selectOneMenu value="\#{bean.selectedEntity}" converter="box.entityConverter">
    <f:selectItems value="\#{bean.entities}" var="e" itemLabel="\#{e.name}" itemValue="\#{e}"/>
</h:selectOneMenu>

<!-- Option 3: Automatic conversion via forClass in the application -->
@Named("modelConverter")
@ApplicationScoped
@FacesConverter(value = "modelConverter", forClass = Model.class, managed = true)
public class ModelConverter extends EntityConverter { }
<!-- Now any component bound to a Model subtype converts automatically without converter="" -->
