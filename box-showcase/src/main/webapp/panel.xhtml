b:panel

b:panel

Box with an optional title (equivalent to a card). Native component (UIComponentBase), with no separate Renderer nor *.taglib.xml — the tag is generated automatically by createTag/namespace/ tagName on the Java class itself.

Attributes

AttributeRequiredDescription
headerNoTitle shown at the top of the box. Omitted, the box has no title.

Example — with a title

<b:panel header="New item">
    Any content goes here.
</b:panel>
Any content goes here.

Example — without a title

<b:panel>
    Box with no title, just the card.
</b:panel>
Box with no title, just the card.
