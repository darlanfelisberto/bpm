b:panel

b:panel

Box with an optional title (equivalent to a card). Self-rendering component (UIComponentBase) registered via @FacesComponent and declared in box.taglib.xml.

Attributes

AttributeRequiredDescription
headerNoTitle shown at the top of the box. Omitted, the box has no title.
styleNoInline CSS style.
styleClassNoCustom CSS class added to the card container.

Example — with a title

<b:panel header="New item">
    Any content goes here.
</b:panel>
Any content goes here.

Example — without a title

<b:panel>
    Box with no title, just the card.
</b:panel>
Box with no title, just the card.
